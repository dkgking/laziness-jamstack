# UI text

- English only until the user asks for languages; then follow `.claude/skills/add-locale/SKILL.md`.
- Every visible string (also `alt`, `placeholder`, `aria-label`) goes through `i18n._("Full English text")` with `useLingui()` from `@lingui/react`. Module-level labels use `msg({ id: "..." })` from `@lingui/core/macro`.
- Never `<Trans>` or the `t` macro; never build messages by concatenation or template strings.
- Numbers and dates through `#/libs/intl`.
- After changing text, run `bun run i18n:extract`, fill every non-English catalog, then `bun run i18n:check`.
